# Tidal Chamber

Metal-rendered animated water clock for iPhone.

## Download

[Download source ZIP](https://github.com/eire360/tidal-chamber/archive/refs/heads/main.zip)

## Setup

Requires Xcode and an iPhone/iPhone simulator running iOS 17 or later.

1. Open `Tidal Chamber.xcodeproj`.
2. Select the Tidal Chamber scheme and a simulator.
3. Run the project.

For a physical iPhone, choose your own development team under Signing & Capabilities.

## Controls

The clock displays local time automatically. The system time-format and reduced-motion preferences are respected.
